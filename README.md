# E-Commerce Analytics Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard built using the Brazilian E-Commerce Public Dataset. The dashboard below analyses e-commerce business performance across sales, customers, products, sellers, payments, order status, reviews, and delivery performance.

The objective of this project is to transform raw e-commerce data into an interactive business intelligence dashboard that helps identify important trends, performance patterns, and customer behaviour.

---

## 🎯 Project Objectives

- Analyse overall sales and order performance.
- Understand customer distribution and purchasing behaviour.
- Identify high-performing product categories and sellers.
- Analyse payment methods used by customers.
- Evaluate order and delivery performance.
- Analyse customer reviews and ratings.
- Create interactive dashboards for business-oriented analysis.
- Develop reusable DAX measures for key performance indicators.

---

## 🛠️ Tools & Technologies

- **Power BI Desktop** – Dashboard development and visualization
- **DAX** – Measures and analytical calculations
- **Power Query** – Data transformation and preparation
- **Data Modelling** – Relationships between multiple e-commerce tables
- **Git & GitHub** – Project version control and portfolio management

---

## 📁 Dataset

The project uses the **Brazilian E-Commerce Public Dataset by Olist**, which contains information related to orders placed through an online marketplace in Brazil.

The dataset includes information about:

- Customers
- Orders
- Order Items
- Products
- Sellers
- Payments
- Reviews
- Geographical locations
- Product categories

The dataset contains multiple related tables, which were modeled in Power BI to create an integrated analytical environment.

# 🧮 DAX & Key Measures

Several DAX measures were created to support the analysis and provide dynamic calculations within the dashboard.

Examples include:

- Total Sales
- Total Orders
- Average Order Value (AOV)
- On-Time Delivery %
- Customer and order metrics
- Sales and revenue trends
- Ranking-based analysis

These measures allow the dashboard to respond dynamically to filters and slicer selections.

# 🔍 Key Insights

The dashboard was designed to identify business patterns such as:

- Overall sales and order trends over time.
- Differences in sales performance across product categories.
- Regional differences in customers and sellers.
- Customer payment preferences.
- Order status and delivery performance.
- Distribution of customer reviews and ratings.
- Seller and product performance across different regions.

The interactive nature of Power BI allows these insights to be explored using filters and slicers rather than relying only on static analysis.

## 📌 Conclusion

This project demonstrates the use of Power BI to transform a multi-table Brazilian e-commerce dataset into an interactive business intelligence dashboard. The analysis provides a comprehensive view of sales, customers, products, sellers, payments, reviews, and delivery performance.

Through data modeling, Power Query transformations, DAX measures, and interactive visualizations, the dashboard enables users to explore business performance from multiple perspectives and identify important trends and patterns.

Overall, the project showcases practical skills in **data analysis, data modeling, DAX, data visualization, and business intelligence** while demonstrating how raw e-commerce data can be converted into meaningful and actionable insights.
